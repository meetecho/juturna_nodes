Juturna nodes documentation
===========================

.. image:: https://img.shields.io/github/license/meetecho/juturna_nodes?style=for-the-badge
    :alt: License

.. image:: https://img.shields.io/python/required-version-toml?tomlFilePath=https%3A%2F%2Fraw.githubusercontent.com%2Fmeetecho%2Fjuturna_nodes%2Frefs%2Fheads%2Fmain%2Fpyproject.toml&style=for-the-badge&color=green

.. image:: https://img.shields.io/github/issues/meetecho/juturna_nodes?style=for-the-badge

----

**juturna-nodes** is the collection of officially supported nodes for
`Juturna <https://github.com/meetecho/juturna>`_: ready-to-use sources,
processing nodes and sinks to build real-time pipelines in minutes.

.. grid:: 2

    .. grid-item::

            need.
