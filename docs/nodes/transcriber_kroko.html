TranscriberKroko¶

processing

Transcribe audio packets using kroko-onnx.

Warning

This node is experimental. Its arguments and its output format may change in any release, without a major version bump.

Node type:

TranscriberKroko

Input:

AudioPayload

Output:

ObjectPayload

Extra:

–

$ pip install juturna-nodes

Configuration¶

Default node arguments, as defined in the node config.toml file. Any of them can be overridden in the node configuration of a pipeline.
